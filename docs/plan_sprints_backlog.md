## 1. Descripción del proyecto
Mi Lista Escolar es una aplicación web sencilla para organizar actividades académicas. Permite agregar tareas, asignarles una materia o categoría, marcar su estado, eliminarlas y filtrarlas. El objetivo es practicar componentes, estado y eventos en React.

## 2. Objetivo general
Desarrollar una aplicación funcional y fácil de utilizar que permita registrar y administrar tareas escolares mediante una interfaz clara.

## 4. Plan de Sprints propuesto
Las duraciones son una propuesta de planificación; ajusta las fechas y estados a lo que realmente trabajes.

### Sprint 1 — Estructura e ingreso de tareas
**Objetivo:** contar con la aplicación base y el registro de tareas.
- PB-01: estructura de React.
- PB-02: interfaz principal.
- PB-03: formulario para agregar tareas.
**Criterio de salida:** la aplicación inicia y permite agregar tareas.

### Sprint 2 — Administración de tareas
**Objetivo:** permitir controlar el estado de las actividades.
- PB-04: marcar tareas como completadas.
- PB-05: eliminar tareas.
- PB-06: filtrar tareas.
- PB-07: validar entradas.
**Criterio de salida:** todas las operaciones se prueban manualmente y funcionan.

### Sprint 3 — Pruebas y entrega
**Objetivo:** revisar la calidad y preparar las evidencias.
- PB-08: pruebas y ajustes visuales.
- PB-09: publicación en GitHub.
- Actualizar este documento con resultados reales, incidencias y capturas.
**Criterio de salida:** repositorio accesible, aplicación comprobada y documentación coherente.
