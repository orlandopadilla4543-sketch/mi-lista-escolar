# Mi Lista Escolar

Aplicación web para organizar actividades académicas desarrollada con React, JavaScript, CSS y Vite.

## Funcionalidades documentadas

- Registrar tareas académicas.
- Marcar tareas como pendientes o completadas.
- Eliminar tareas.
- Filtrar tareas por estado.
- Consultar contadores de tareas totales, pendientes y completadas.

## Tecnologías

- React
- JavaScript
- CSS
- Vite

## Ejecución local

Con Node.js instalado, ejecutar:

```bash
npm install
npm run dev
```

Para verificar la compilación de producción:

```bash
npm run build
```

La compilación debe ejecutarse después de los últimos cambios y antes de afirmar que la versión final está validada.
