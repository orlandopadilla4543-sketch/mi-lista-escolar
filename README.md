# Mi Lista Escolar

Aplicación académica construida con React y Vite para organizar tareas escolares.

## Funciones de la aplicación
- Agregar tareas con nombre y materia o categoría.
- Validar que el nombre de la tarea no esté vacío.
- Marcar una tarea como completada o devolverla a pendiente.
- Eliminar tareas de la lista.
- Filtrar tareas por todas, pendientes o completadas.
- Mostrar los contadores de tareas totales, pendientes y completadas.
- Mostrar mensajes de confirmación para las acciones realizadas.

## Requisitos
- Node.js LTS.
- Conexión a internet para instalar las dependencias. La fuente externa es opcional; se usan fuentes alternativas si no está disponible.

## Ejecutar en la computadora
1. Descomprime el ZIP.
2. Abre una terminal dentro de la carpeta `mi_lista_escolar`.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre la dirección que muestre Vite, normalmente `http://localhost:5173`.

## Comprobar la compilación
Ejecuta `npm run build`. Si termina sin errores, la compilación se completó correctamente.

## Estructura
- `index.html`: página de entrada.
- `src/main.jsx`: punto de entrada de React.
- `src/App.jsx`: interfaz, estado y funciones de las tareas.
- `src/styles.css`: estilos.
- `docs/plan_sprints_backlog.md`: backlog, calendario, ajustes y pruebas.
