# Mi Lista Escolar

Aplicación académica sencilla construida con React y Vite para organizar tareas escolares.

## Funciones
- Agregar tareas con nombre y materia/categoría.
- Marcar tareas como completadas.
- Eliminar tareas.
- Filtrar todas, pendientes y completadas.
- Ver un resumen del total, pendientes y completadas.
- Validación básica del nombre de la tarea.

## Requisitos
- Node.js LTS instalado.
- Conexión a internet para instalar dependencias (y para cargar la fuente de Google Fonts; el sistema funciona con fuentes alternativas si no está disponible).

## Ejecutar en la computadora
1. Descomprime el ZIP.
2. Abre una terminal dentro de la carpeta `mi_lista_escolar`.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre en el navegador la dirección que muestre Vite, normalmente `http://localhost:5173`.

## Compilar para comprobar
Ejecuta `npm run build`. Si termina sin errores, la compilación se completó correctamente.

## Estructura
- `index.html`: página de entrada.
- `src/main.jsx`: punto de entrada de React.
- `src/App.jsx`: interfaz y funciones.
- `src/styles.css`: estilos.
- `docs/`: documentación académica.

## Nota académica
La planificación de Sprints en `docs/` es una propuesta inicial. Registra como avances realizados únicamente las funciones que hayas ejecutado y comprobado. Actualiza el estado del backlog conforme termines cada tarea.
